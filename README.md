## Features
- Animated hero: a network that runs breadth-first search and highlights the shortest path on click
- Interactive hospital dashboard (Chart.js) built from my Excel pivot tables
- Four projects with downloadable reports, workbook and slides
- Education, achievements (NASA hackathon), experience and contact form
- Responsive layout, keyboard focus styles, light/dark support, reduced-motion support

## Technologies
HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js, Git/GitHub, Vercel.

## Run locally
No build step. Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deploy
1. Push this folder to a new GitHub repository.
2. In Vercel choose **Add New > Project**, import the repository, keep the defaults (Framework: Other, no build command) and click **Deploy**.
3. Paste the Vercel URL above. Every push to `main` redeploys automatically.
